# Security

Recipes are untrusted data. They must pass the shared schema validator before any state replacement. Imported JSON never supplies HTML, code, module names, network endpoints, or unrestricted CSS.

The runtime uses bounded graph sizes, finite values, an acyclic graph, bounded work per trigger, bounded pending timers, capped visual history, and cancellation on reset/replacement. These guards protect a local teaching tool; they are not a promise that arbitrarily large third-party content is safe to execute.

For a reproducible issue, record the browser/version, a minimal sanitized recipe, and expected versus actual behavior. Use [private vulnerability reporting](https://github.com/hocky0301/patchlight/security/advisories/new) for sensitive findings. This channel is enabled for this repository. Do not post secrets or personal information in a public report.

Do not include real device serial numbers or credentials in test fixtures.
