## ブラウザテストの範囲

Playwright **1.63.0**。Chromium デスクトップ、Firefox デスクトップ、WebKit デスクトップ、Chromium 390×844 / touch の4プロジェクト。デスクトップ3件のタッチ専用ケースは意図したスキップであり、動作失敗ではない。

主な確認内容:

- 未配線では光らず、2端子の接続と1回の入力で光る。
- しきい値での停止・通過、遅延出力、リセットやレシピ変更による遅延の取消。
- 2回ごとの出力、明るさ入力を変えてもカウントが続くこと、描画の色を変えても既存の絵が残る。
- 線の削除・取消、マウス・タッチ・キーボードの移動。
- JSON ダウンロードと再読み込みの一致、不正 JSON・未知のキー・大きすぎるファイルの拒否。
- 作品名に含まれる HTML を実行せず、文字として表示。
- 保存作品の復元、別ブラウザコンテキストへの URL 共有。
- ページ内アンカーや壊れた共有リンクで、保存作品を失わない。
- 共有・作例を開いて編集した後も、再読み込みで編集を維持。
- 空の数値欄を0として保存しない。32個のブロックを重ねずに整列する。
- 保存不可の環境でも動作し、保存できていないことを表示する。
- 名前変更・日本語IMEの確定・取消、文字入力やモーダル・ドラッグ中のショートカット境界。
- 取り消し・やり直しと新しい編集での履歴分岐、空の作品とブロック分類。
- 光・音・絵の切替と説明の一致、色を保ったままの設定変更、SVGの安全な文字出力と長い作品名。
- スマートフォンで絵の保存・出力切替がほかの要素に隠れず押せること。

**0.2.0 最終全体実行: 121件成功、意図したスキップ3件、失敗0件、再試行での成功0件。** 31シナリオ×4プロジェクトの124ケースを実行した。Chromium / Firefox / WebKit は各30件成功とタッチ専用1件スキップ、モバイル設定は31件すべて成功。2026-09-15 00:34:24 UTC に開始し、82.82秒で完了した。追加の修正確認も24件すべて成功。

途中で見つかったモバイル出力操作の重なり、日本語IMEの確定、ドラッグ・ダイアログ中の取り消し、出力切替後の説明、長いSVG作品名を修正し、この全体実行に回帰確認を含めた。macOS WebKitのリンク移動は標準の Option+Tab で検証した。

## 30秒目標の確認

初回経路は、未接続では光らず、**端子2回＋押す1回**で光ることを自動テストで確認した。これを、人が画面を読む・理解する時間の測定とは扱わない。

未説明の人が30秒以内に「ブロックをつなぐ意味」を理解できるかは**未測定**。[ROADMAP.md](ROADMAP.md#人による30秒確認) に、人による観察手順と合格条件を記載した。

## 確認していない範囲

- 実機接続、GATT 通信、公式アプリ・SDK・公式レシピとの動作互換。
- 実際の iPhone / iPad / Android 端末。モバイル幅とタッチ入力のブラウザテストを、実端末検証と同一視しない。
- 音の聴感評価、支援技術の網羅的な試験、アクセシビリティ規格への適合判定。
- 初回訪問者を募集して行う30秒の理解テスト。

## 再実行

```sh
npm test
npm ci
npx playwright install chromium firefox webkit
npm run test:browser
node scripts/package.cjs
```

ブラウザテストの失敗時には `test-results/` に証拠を残す。レポートや `node_modules/`、ブラウザバイナリーは公開サイトと配布 ZIP に含めない。
